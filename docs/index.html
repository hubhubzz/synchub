Simple folder backup

SyncHub

Copy a local folder to Google Drive from a small Rust command-line app, powered by your existing rclone setup.

Start with a preview

synchub --dry-run ~/Documents gdrive:Backups/Documents

When the preview looks right, run the same command without --dry-run. SyncHub keeps extra files on Drive; it does not delete them.
