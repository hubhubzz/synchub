synchub

Privacy Policy

Effective date: October 28, 2026

This policy explains how synchub, a local Rust command-line application maintained in the hubhubzz/synchub project, accesses and handles information when you use it to upload a folder to Google Drive.

How the app works

synchub runs on your computer. You choose a local folder by running the command. The app connects directly from your computer to Google OAuth and the Google Drive API over HTTPS. synchub does not operate an account service, application server, analytics service, or cloud storage service, and it does not send your Google Drive data to the project maintainers.

Google account and Drive data

synchub requests the Google Drive drive.file OAuth permission. It does not request access to your Gmail, contacts, profile, or entire Drive. The app uses Drive access only to provide its sync function.

When you run a sync, synchub reads regular files within the local folder you selected, including files in its subfolders, and skips symbolic links. It reads file contents to upload them and calculates a checksum to determine whether a file has changed. It sends the selected files' names, contents, and upload metadata to Google Drive. It also reads the names, IDs, file types, and checksums needed to locate and compare files in the synchub folder it manages in Drive. It creates new files, updates changed files, and skips unchanged files. It does not delete Drive files when they are removed locally.

synchub does not request Google user data for advertising, sell or rent Google user data, use it for unrelated purposes, or transfer it to data brokers. The app has no AI features and does not use Google APIs or Google user data to train AI models or create, request, or distribute AI-generated non-consensual intimate imagery (NCII). Google API data is used only to provide the sync feature that you initiate.

OAuth credentials and local storage

Google sign-in opens in your system browser. synchub uses a temporary loopback callback on your computer and PKCE to complete authorization; the app does not receive or store your Google password. Google returns an authorization code and access credentials to the app. synchub stores the access token and refresh token in synchub/google-token.json inside your operating system's user configuration directory so later syncs can continue without repeated sign-in. On Unix-like systems, the app restricts the token directory to the current user and the token file to that user. On other systems, the file uses the permissions provided by the operating system. The app does not separately encrypt this local token file.

The token remains on your device until you remove the local token file. You can also revoke synchub's access in your Google Account third-party connections. Revoking access may require you to authorize again before another sync.

Retention and deletion

synchub does not retain your Google Drive files or file contents on a synchub server. Uploaded copies remain in your Google Drive until you delete them there. Removing a local file does not remove its Drive copy. The OAuth token is retained locally as described above.

Other services

Google processes sign-in, OAuth credentials, and Drive transfers under its own Privacy Policy and applicable terms. This informational website is hosted by GitHub Pages; GitHub may process technical information such as network requests under its Privacy Statement. If you post to GitHub Issues, your post may be public. Do not include files, tokens, or other sensitive information in an issue.

Your choices and contact

You control which local folder to sync and which Google account to authorize. Use synchub --dry-run <folder> to list local files without connecting to Google. You can stop a sync, revoke access through Google Account settings, and remove the local token file. For questions about this policy or the app, contact the maintainers through synchub GitHub Issues.

Changes to this policy

This policy will be updated if the app's data practices change. The effective date above identifies the latest revision. The app will not use Google user data for a new purpose without updating its disclosures and obtaining any consent required by Google policy.

synchub's use of Google user data is subject to the Google API Services User Data Policy, including its Limited Use requirements.
